Banking Statement Converter Platform

Converts internal domain data to MT940, MT942, camt.052 and camt.053 banking files.

Quick Start

1. Generate random data: POST /api/random-statements

2. Run conversion: POST /api/conversions

3. Check status: GET /api/conversions/jobs/{jobId}
